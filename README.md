# 烟农画像与精准计划分配系统 V2.0

这是一个纯前端静态网页，可直接部署到 GitHub Pages。

## 文件

- `index.html`：网页入口
- `烟农数据导入模板_V2.0.xlsx`：网页内“下载模板”按钮引用的 Excel 模板

## GitHub Pages 部署

1. 在 GitHub 新建一个公开仓库，例如 `tobacco-farmer-plan`。
2. 上传本目录内全部文件到仓库根目录。
3. 进入仓库 `Settings` -> `Pages`。
4. `Build and deployment` 选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. 保存后等待 1-3 分钟。

公开链接格式通常为：

`https://你的GitHub用户名.github.io/仓库名/`
