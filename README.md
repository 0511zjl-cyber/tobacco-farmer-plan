# 烟农画像与计划分配系统 V3

本系统是在烟农五维评价画像 V1.0 基础上升级形成的纯前端、本地运行版应用。系统先完成烟农评分、画像和分类，再依据种植意愿、画像得分、分类政策和历史亩产，自动完成全市种植面积、收购计划的分户分解。综合看板按 `DASHBOARD_DESIGN_V2.2.md` 完成决策指标、分类结构、五维能力、烟站排名、风险预警、精准计划结果和重点关注烟农展示。

烟农数据、计划参数和审核意见均在当前浏览器中处理，不会主动上传到外部服务器。

## 一、主要功能

### 1. 烟农画像评价

- Excel、CSV、JSON本地批量导入
- 基础归属信息按“县”“烟站”两个独立字段导入，不再使用乡镇字段
- 五个维度、27项指标自动评分
- 综合得分、数据完整度、风险等级并行输出
- 自动归类：核心标杆户、稳定经营户、低效预警户、老龄维持户
- 新烟农直接归为稳定经营户，并标记“新烟农观察期”
- 非新烟农年龄达到65岁，归为老龄维持户
- 信用红线、画像标签、服务建议自动生成
- ECharts 综合看板、五维雷达图、烟站排名、风险预警和单户评分明细
- 综合看板支持按县、烟站联动筛选，指标卡、图表、精准计划结果和重点关注名单同步重算

### 2. 精准计划分配七步闭环

1. **全市参数设置**：录入固定种植面积、固定收购计划、意愿/画像权重和分类系数。
2. **面积初分**：以种植意愿为基础，叠加得分和分类系数计算理论面积。
3. **面积找平**：在单户申请面积±5亩内，将分户面积合计闭环到全市固定面积。
4. **亩产调整**：已有烟农以近三年加权亩产为基准，新烟农以全市平均亩产为基准，在±10%范围内调整。
5. **收购计划找平**：将分户收购计划合计闭环到全市固定收购总量。
6. **异常审核**：核查边界值、反向调整、信用红线、历史数据缺失等事项。
7. **结果导出**：导出Excel工作簿、分户CSV、异常审核表和JSON完整备份。

## 二、最快使用方式

1. 解压整个文件夹。
2. 双击 `启动应用.bat`，或直接打开 `index.html`。
3. 在“数据导入”页面下载并填写 `烟农数据导入模板.xlsx`。
4. 上传Excel，完成评分、画像和分类。
5. 点击左侧“精准计划”，依次完成七个步骤。
6. 在第七步完成最终校验后导出结果。

可以先点击“直接加载示例数据”，无需准备Excel即可测试全部功能。

## 三、计划分配核心规则

系统采用以下原则：

> 申请定基数、得分定权重、分类定方向、历史定单产、总量做找平、边界保合规。

### 1. 面积初分公式

```text
理论面积 = 全市总面积 × [
  意愿权重 ×（该户申请面积 ÷ 全市申请面积合计）
  + 画像权重 ×（该户画像加权值 ÷ 全市画像加权值合计）
]
```

其中：

```text
画像加权值 = 申请面积 × 得分系数 × 分类系数
得分系数 = 0.8 + 0.4 × 综合得分 ÷ 100
```

默认权重：种植意愿70%，画像调节30%。

### 2. 分类调节系数

| 类别 | 默认系数 | 面积首轮区间 | 亩产首轮区间 | 导向 |
|---|---:|---:|---:|---|
| 核心标杆户 | 1.10 | 申请面积至+5亩 | 0%至+10% | 优先保障、优先增加 |
| 稳定经营户 | 1.05 | -2亩至+5亩 | -3%至+8% | 重点倾斜 |
| 新烟农 | 1.00 | -2亩至+2亩 | 按全市平均亩产 | 稳妥安排 |
| 低效预警户 | 0.90 | -5亩至申请面积 | -10%至0% | 适度压减 |
| 老龄维持户 | 0.85 | -5亩至申请面积 | -8%至0% | 维持或适度压减 |

首轮政策区间不足以完成总量闭环时，系统可放宽到单户申请面积±5亩、基础亩产±10%的硬边界，并自动生成异常审核事项。

### 3. 历史基础亩产

- 有历史数据：使用“近3年加权亩产kg/亩”。
- 新烟农：使用“全市固定收购计划÷全市固定种植面积”。
- 非新烟农历史亩产缺失：暂用全市平均亩产，并进入异常审核。

### 4. 亩产调整依据

```text
产能指数 = 生产能力标准分×60%
         + 质量水平标准分×30%
         + 信用行为标准分×10%
```

系统根据产能指数和烟农分类确定初始浮动，再通过收购总量找平完成最终核定亩产。

## 四、必须满足的刚性约束

- 分户最终种植面积合计＝全市固定种植面积。
- 分户最终种植面积统一按1亩精度分配，不提供精度调节。
- 分户最终收购计划合计＝全市固定收购计划。
- 单户最终面积在申请面积±5亩范围内。
- 单户最终亩产在基础亩产±10%范围内。
- 新烟农基础亩产为全市平均亩产。
- 不可行时系统不突破边界，而是提示调整总量、面积结构或重新征集意愿。

## 五、异常审核规则

系统自动识别：

- 面积调整达到±5亩边界
- 亩产调整达到±10%边界
- 核心标杆户被压减面积
- 低效预警户或老龄维持户增加面积
- 信用红线烟农进入计划
- 新烟农申请面积明显偏大
- 历史亩产缺失
- 为闭环突破首轮分类政策区间
- 全市面积或收购计划未闭环

审核状态包括：待审核、通过、需调整、已说明。

## 六、结果导出

### Excel工作簿

包含四个工作表：

1. 分户计划清单
2. 分类汇总
3. 异常审核
4. 参数校验

### 其他导出

- 分户计划CSV
- 异常审核CSV
- JSON完整方案备份
- 原有烟农画像评价结果CSV
- 27项指标评分明细CSV

## 七、导入数据要求

- 支持 `.xlsx`、`.csv`、`.json`，不支持旧版 `.xls`。
- Excel读取第一个工作表“烟农数据”。
- 县、烟站均为必填字段；烟站用于同群体分位和看板排名。
- 烟农编号必须唯一。
- 百分比可填 `85` 或 `0.85`。
- 是/否字段支持：是、否、1、0、true、false。
- 出生日期建议使用 `YYYY-MM-DD`。
- 制定计划必须填写：种植意愿亩数、近3年加权亩产；新烟农可不填历史亩产。

## 八、文件说明

- `index.html`：推荐入口，已包含全部样式和程序代码。
- `烟农画像与计划分配系统_V3.html`：与 `index.html` 内容一致的当前版本归档入口。
- `烟农画像与精准计划系统_V2.1.html`：历史版本归档入口。
- `烟农数据导入模板.xlsx`：正式数据模板，包含27项评分指标、计划参数和计划规则说明。
- `烟农示例数据.xlsx`：可直接导入系统验证画像和看板的示例数据。
- `PROJECT_CONTEXT.md`：业务逻辑、评分口径与工程约束。
- `DASHBOARD_DESIGN_V2.2.md`：综合看板设计要求。
- `README.md`：本说明文件。

## 九、内网部署

### 直接运行

复制整个文件夹到目标电脑，打开 `index.html`。

### Python临时服务器

双击 `启动本地服务器.bat`，或运行：

```bash
python -m http.server 8000
```

浏览器访问：

```text
http://127.0.0.1:8000/index.html
```

### 正式多人协同版

本版本数据保存在每台电脑各自的浏览器中，适合单机测算、试点验证和汇报演示。正式多人协同时，建议升级为：

- 前端：Vue 3
- 后端：Spring Boot 或 FastAPI
- 数据库：MySQL / PostgreSQL
- 文件存储：MinIO
- 权限：市局、县局、烟站、烟技员分级权限
- 功能：方案审批、异议复核、历史版本、操作审计

## 十、数据安全

- 应用不会主动向外部网络发送烟农数据。
- 最近一次数据、计划参数和审核意见保存在浏览器 localStorage。
- 使用公共电脑后应点击“清空全部数据”。
- 不建议导入身份证号码、银行卡号等非必要敏感信息。
- 计划分配结果应经过业务人员审核、公示和异议复核后正式使用。

## 十一、浏览器建议

建议使用新版 Microsoft Edge 或 Google Chrome。若离线Excel解析不兼容，可将数据另存为CSV后导入。
